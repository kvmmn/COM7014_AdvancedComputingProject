# Reproducibility Standard

Any technical result published by this project must have:

- a defined source and licence for its data;
- a clear unit of observation;
- documented inclusion, exclusion, and preprocessing rules;
- a baseline or comparator established before headline claims;
- fixed seeds where randomness matters;
- train-only fitting of preprocessing when prediction is involved;
- an environment or dependency record;
- a clean, top-to-bottom successful run;
- machine-readable frozen metrics where appropriate;
- figures generated from the same frozen results;
- limitations and uncertainty stated beside the interpretation;
- no credential, personal path, private identifier, or restricted record.

The private results ledger is the first source of truth. Numbers move into public files only after independent checking and student approval.
