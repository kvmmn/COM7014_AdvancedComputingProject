# COM7014 Working Rules

This repository is the working area for COM7014 Advanced Computing Project.

Before changing the project:

1. Read `PROJECT_BRAIN/README.md` and the relevant files in `PROJECT_BRAIN/PUBLIC/`.
2. When the local-only directory exists, read `PROJECT_BRAIN/PRIVATE/README.md`, `ASSIGNMENT_CONTROL.md`, `DECISION_LOG.md`, `PROJECT_LOG.md`, and the records relevant to the task.
3. Treat the current brief, rubric, tutor guidance, dataset rules, ethics approval, and submission portal as more authoritative than lesson summaries or generic process advice.
4. Record every consequential decision, source, result, change, risk, and supervisor instruction as it occurs.
5. Do not begin assessed drafting until the student has confirmed the scope, deliverables, structure, and word budget.
6. Do not collect data or begin artefact development before the required proposal and ethics approval have been granted.
7. Run `python3 scripts/public_preflight.py` before every public commit.
8. Never publish lesson files, assessment documents, private notes, tutor communications, ARMS records, personal data, credentials, restricted data, or unapproved drafts.

The repository is public. If publication status is uncertain, keep the material local and record it in the private publication review queue.
