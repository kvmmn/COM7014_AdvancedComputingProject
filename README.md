# COM7014 Advanced Computing Project

This is the working repository for the COM7014 Master's project at Arden University.

The selected topic is a per-series router that gives a calibrated probability that a time-series foundation model should be trusted, and falls back to a classical forecaster, including intermittent-demand methods, when that probability is too low. Routing itself is not new; the contribution is calibrated trust, explicit deferral and transfer to a field the router was not trained on. The working title, research questions, method, and evaluation protocol are in [`TOPIC.md`](TOPIC.md).

The topic was selected on 2026-09-28. Dataset discovery and literature extraction are active, but no dataset has been downloaded and no model or experiment has been run. Proposal approval, ethics approval, data collection, and artefact development have not started.
