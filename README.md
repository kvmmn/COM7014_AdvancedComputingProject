# COM7014 Advanced Computing Project

This public repository will contain the reproducible, publication-safe parts of the COM7014 Master's project at Arden University.

The project is currently in the setup and topic-selection stage. No research topic, dataset, methodology, artefact, or reported result has been selected yet.

## Project control

The public project control layer is in [`PROJECT_BRAIN`](PROJECT_BRAIN/README.md). It documents the workflow, publication boundary, reproducibility standard, and current status without exposing private academic records or restricted material.

## Publication boundary

Only reviewed material is published here. Teaching files, assignment documents, internal planning, supervisor communications, ethics records, personal data, restricted datasets, credentials, working drafts, and the private project log remain local and are excluded from Git.

See [`PROJECT_BRAIN/PUBLIC/STATUS.md`](PROJECT_BRAIN/PUBLIC/STATUS.md) for the current phase and known blockers.
